# Тепло — дневник питания

Тёплое бежевое приложение для iPhone: готовый план питания на месяц, дневник, вода, список покупок и бережный прогресс. Персонально для **Даниелы**.

Это **PWA**: оно устанавливается на iPhone прямо из Safari, открывается с домашнего экрана без адресной строки и работает офлайн. App Store и Mac для этого не нужны.

---

## Что уже есть

- **Онбординг** с личными параметрами: Даниела, 23 года, 175 см, 80 кг, цель 68 кг.
- **План на месяц**: 4 недели, 28 дней, 4 приёма пищи в день. В основе — 7 сбалансированных меню и 28 простых рецептов; каждую неделю они идут в новом порядке, чтобы дни не повторялись подряд.
- **Дневник**: отмечай блюда по плану в одно касание, добавляй продукты из справочника, своё блюдо или еду из плана.
- **Вода**: 8 стаканов по 250 мл, цель 2 л.
- **Прогресс**: вес, график, темп, прогноз до цели, история замеров.
- **Список покупок** на неделю с отметками и копированием.
- **Настройки**: имя, рост, дата рождения, цель, калории, БЖУ, вода, экспорт/импорт JSON.
- **Офлайн-режим** и установка на домашний экран.
- Все данные хранятся **только на телефоне** в `localStorage`, никуда не отправляются.

## Личный расчёт

Для здоровой взрослой девушки 23 лет, 175 см, 80 кг (Даниела):

- основной обмен по формуле Миффлина — около **1 618 ккал**;
- суточная норма при умеренной активности (7–8 тыс. шагов) — около **2 225 ккал**;
- целевой дефицит — около **575 ккал**;
- цель — **1 650 ккал**, **135 г белка**, **58 г жиров**, **145 г углеводов**, **28 г клетчатки**;
- ожидаемый темп — **0,4–0,6 кг в неделю**. В первые недели может уходить больше за счёт воды — это нормально.

Меню на месяц: **28 дней**, в день **1 636–1 667 ккал**, в среднем **1 653 ккал**, **135 г белка**. Это не «диета на 1200», а дефицит, который проще удержать дольше нескольких недель. Через 28 дней цикл повторяется — закупки и готовка остаются простыми.

> Это не медицинская рекомендация. При беременности, расстройстве пищевого поведения, проблемах со щитовидной железой, ЖКТ или приёме лекарств сначала обсуди питание со специалистом. Не опускайся ниже 1 500 ккал без наблюдения.

## Как установить на iPhone

### Вариант 1. Netlify Drop — 2 минуты

1. Скачай папку `teplo` (или архив `Тепло-приложение.zip`) и распакуй, если нужно.
2. Открой на компьютере [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащи **папку `teplo`** (внутри должны быть `index.html`, `css`, `js`, `icons`) в окно браузера.
4. Netlify выдаст ссылку вида `https://something.netlify.app`.
5. Отправь ссылку на iPhone, открой её **в Safari**.
6. Нажми **«Поделиться»** → **«На экран Домой»** → **«Добавить»**.
7. Запускай «Тепло» с домашнего экрана. Приложение будет работать офлайн.

Важно: открывать нужно именно в Safari, а не во встроенном браузере Telegram/Instagram.

### Вариант 2. GitHub Pages

1. Создай репозиторий и загрузи содержимое папки `teplo` в корень.
2. Settings → Pages → Deploy from a branch → `main` / `root`.
3. Открой выданную ссылку в Safari и добавь на домашний экран.

### Локальный просмотр на компьютере

В папке `teplo`:

```bash
python -m http.server 8787
```

Открой `http://127.0.0.1:8787`. Для проверки на iPhone в той же Wi-Fi сети можно открыть `http://IP-компьютера:8787`, но офлайн-режим и установка корректно работают на HTTPS (Netlify/GitHub Pages).

## Что важно знать

- **Это не нативное приложение из App Store.** Это устанавливаемая PWA: иконка на домашнем экране, полноэкранный режим, офлайн. Для личного использования этого достаточно.
- **Push-уведомления при закрытом приложении** на iOS для PWA не работают. Напоминаний в этой версии нет.
- **Данные привязаны к браузеру/устройству.** Если очистить данные Safari или удалить приложение с домашнего экрана, записи пропадут. Делай резервную копию в настройках: «Скачать резервную копию».
- **Экспорт** — JSON-файл. Его можно сохранить в «Файлы» или отправить себе.
- **Импорт** — загрузить тот же JSON обратно.
- **Сброс** — удаляет всё и возвращает онбординг.

## Как менять план

Все рецепты, продукты и КБЖУ лежат в `js/data.js`:

- `BASE_PLAN` — 7 базовых дней, по 4 приёма пищи;
- `WEEK_ORDERS` — порядок этих дней в каждой из 4 недель;
- `PLAN` — готовый плоский план на 28 дней (собирается автоматически);
- `MONTH_WEEKS` — названия и фокус каждой недели;
- `FOODS` — справочник продуктов на 100 г;
- `SHOP` — список покупок;
- `TIPS` — подсказки на главной.

После правок обнови номер кэша в `sw.js` (`const CACHE = 'teplo-v1.2.0'` → `v1.2.1`), чтобы установленное приложение подтянуло новую версию.

Цели по калориям и БЖУ удобнее менять в самом приложении: **шестерёнка → Ориентиры на день**.
